# Network

Personal network graph — one file per person.

## File naming

`First Last [context].md` — context is whatever disambiguates: a shared workplace, school, city, or phone number.

## Structure

```
people/
  PERSON_TEMPLATE.md   ← copy this for each new person
  ...
```

## Connections

Files link to each other via `[[Name [context]]]` (Obsidian-compatible) or standard relative markdown links.
